Deployment target▾

Deploy Federation Hub on this machine or a separate host via SSH. One rule: the hub cannot share an OS with TAK Server — the hub's JVM + MongoDB would contend with TAK Server's JVM + Postgres for RAM (MongoDB alone defaults to ~50% of system memory) and a single outage would take down both. A console host with no TAK Server can run the hub locally; a host already running TAK Server must point at a separate target (a different machine, or a separate VM on the same physical host — just not the same OS as TAK Server).

Authentik SSO login▾

Enable Authentik OAuth on the Federation Hub UI so users can log in with their Authentik credentials instead of importing a client certificate. Creates an OAuth2/OIDC application in Authentik and patches federation-hub-ui.yml on the remote host. Users in the authentik Admins group get admin access.

Users may see Login with Keycloak on the hub — that is the OIDC handoff to Authentik. After once, a browser session cookie often means the next visit skips that click (until the cookie expires or data is cleared).

Client cert login (webadmin-fed.p12) continues to work alongside OAuth.
