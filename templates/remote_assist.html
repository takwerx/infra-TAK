⚠ Uninstall EUD Remote Assist?

This will stop and remove the containers and database volume. Device data in PostgreSQL will be deleted.

Install CoTURN Server

Provide credentials and the public IPv4 address where the TURN server will be reachable.

8–128 chars: letters, digits, and . _ @ + = ! % ^ - — no spaces, quotes, or other symbols.
Remote Assist TURN runs on 3479 — port 3478 is reserved for NetBird, so both can be installed on the same box in any order. Clients are told which port to use.

Configure NetBird CoTURN

Adds a dedicated Remote Assist credential to NetBird's coturn (its own secret stays private) and restarts that container.

8–128 chars: letters, digits, and . _ @ + = ! % ^ - — no spaces, quotes, or other symbols.

Uninstall CoTURN?

This removes the CoTURN container and its configuration. EUD Remote Assist itself is unaffected.
