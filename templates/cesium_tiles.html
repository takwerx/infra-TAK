Remove Cesium 3D Tiles?
This will disable the module and permanently delete all tile datasets from ~/cesium-tiles/.

This cannot be undone. Back up any datasets you want to keep before continuing.
1
Get a 3D Tiles dataset. Any directory that contains a tileset.json file at its root is a valid Cesium 3D Tiles dataset. The folder also contains the tile files (.b3dm, .pnts, .i3dm, etc.) referenced by that JSON.
2
Choose a descriptive name. In the Dataset Name field below, enter a name that matches what the data represents — e.g. downtown-san-diego or incident-alpha-buildings. Use lowercase with hyphens, no spaces. This name becomes part of the ATAK URL and appears in the TAK client overlay manager, so field users can identify it at a glance.
3
Option A — Upload via browser. Enter a dataset name, then either:
• Select Folder — pick the dataset folder directly from your computer.
• Select .zip — zip the dataset folder first so the tileset.json is at the top level inside the zip (not nested inside a sub-folder), then upload the zip.
4
Option B — Place via SFTP. Copy the dataset folder directly to the server at:
~/cesium-tiles/<dataset-name>/tileset.json
The dataset will appear in the list below automatically — no upload needed.
5
Copy the ATAK URL. Once the dataset appears in the table below, click its URL chip to copy it. Paste that URL into ATAK's Map Manager (see How to Connect in ATAK below).

1
Open ATAK and launch the Map Manager
2
Go to the MOBILE tab
3
Select the Down Arrow, then the Add (+) button
4
Type in the URL to the dataset's tileset.json — e.g. https://{{ ct_domain }}/my-dataset/tileset.json
ATAK will send a request to the URL to check for available services and confirm it is Cesium 3D Tiles content.
5
If the connection succeeds, a window shows available services. Click the checkbox next to the tileset to import it.
6
The dataset is now available under the Overlay Manager as a 3D layer. ATAK caches tiles locally in atak/3dtilescache/.
