Backdoor (IP:5001)

▾

If Authentik or the domain is down, you can always reach the console at:

https://{{ settings.get('server_ip', 'SERVER_IP') }}:5001

Accept the self-signed cert and log in with your console password. Full lockout? If you can't log in at all, you have to get on the CLI: the README on the GitHub repo has the exact commands to run on the server to reset the password (e.g. ./reset-console-password.sh).

Force update via CLI

▾

If the Update Available banner isn't showing, or the Update Now button isn't responding, you can force-update the console directly from the server CLI. SSH in and run:

cd $(grep -oP 'WorkingDirectory=\K.*' /etc/systemd/system/takwerx-console.service)
git fetch https://github.com/takwerx/infra-TAK.git main
git checkout --force -B main FETCH_HEAD
grep '^VERSION' app.py
sudo systemctl restart takwerx-console

The grep '^VERSION' line confirms the new version is on disk before the restart. After systemctl restart the console will be back in 10–15 seconds.

Console password

▾

This is the password you set when you ran start.sh. The same password is used to log in at the backdoor (above) and for Uninstall all services on the Console page. We don't store the plaintext, so it can't be shown here. Forgot it? Use the form below if you're logged in; for a full lockout you need the CLI — see the README on the GitHub repo.

Reset console password

▾

Enter your current password and choose a new one. The console will restart and you'll use the new password for 5001 and Uninstall all. Only works when you're already logged in. For a full lockout, use the CLI (README has the commands).

Server hardening — SSH port

▾

Changing the SSH port from the default (22) reduces automated scans and is a common hardening step. Keep another session open (e.g. a second SSH or the console in the browser) until you confirm you can connect on the new port, or you may lock yourself out.
