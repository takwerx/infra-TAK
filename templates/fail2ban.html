🌐 Trusted Upstream Networks
If this box sits behind a reverse proxy, cloud load balancer, or gateway (Azure App Gateway, an Nginx/HAProxy in front, etc.), inbound traffic appears to come from the upstream's handful of IPs. A jail trip could then ban the gateway itself — and since it is the only way in, every site 502s while the box is perfectly healthy. Add the upstream's subnet(s) here and they are whitelisted in every jail, and re-applied automatically on each jail rebuild. Localhost and the box's own attached private subnet are always trusted.

MediaMTX RTSP Jail Disabled
Monitors the mediamtx systemd service log for failed stream authentication — credential guessing against RTSP/RTMP/SRT/WebRTC. Successful stream pulls are never counted, so a client opening many streams at once (a video wall, a multi-feed dashboard) cannot be banned by this jail. Guard Dog email alert fires on ban.
A ban here blocks the media ports only (1935/8322/8554/8555/8888/8889 tcp, 8000/8001/8189/8890 udp), so it does not cut the banned IP off from TAK Server or this console. Repeat offenders keep earning media-scoped bans — the Repeat Offenders jail below is set to skip this one, because a permanent all-ports ban is exactly what this scoping exists to prevent.
