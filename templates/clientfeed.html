Publishes the ATAK/iTAK/WinTAK clients currently connected to this TAK Server as a read-only map feed. Each agency gets its own URL, scoped to the TAK channels you choose, and any one can be revoked without affecting the others.

Speaks the ArcGIS REST FeatureServer spec and GeoJSON, so it works with mapping and CAD clients generally — no Esri account required, yours or theirs. No new port is opened. Only end-user devices are published, never the AVL, ADS-B or TFR feeds this server ingests.

Each agency gets its own URL. ArcGIS Online and ArcGIS Pro need the first form; plain REST and GeoJSON consumers can use the shorter second one:
https://{{ feed_host }}/feed/<token>/rest/services/TAKClients/FeatureServer  — ArcGIS Online / Pro
https://{{ feed_host }}/feed/<token>/FeatureServer  — plain REST / GeoJSON
/FeatureServer/0/query?where=1=1&outFields=*&f=json  — ArcGIS REST &f=geojson  — GeoJSON
Positions refresh when the consumer polls. Most CAD and mapping clients poll once a minute.
