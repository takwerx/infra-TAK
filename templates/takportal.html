TAK Portal is a lightweight user-management portal that integrates with Authentik and TAK Server for streamlined certificate and account control.

Features: User creation with auto-cert generation, group management, mutual aid coordination, QR code device setup, agency-level access control, email notifications.

Requires: Docker · Authentik · TAK Server with LDAP connected
