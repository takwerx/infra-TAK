🚀 First-Time Setup — Connect CloudTAK to TAK Server ▼

CloudTAK needs its own TAK Server user + certificate to connect. Follow these steps once after install:

STEP 1 — Create a CloudTAK admin user in TAK Portal
  1. Open TAK Portal → Users → Create User
  2. Set the username to cloudtakadmin (or your preferred name)
  3. This must be a regular user — do NOT check the admin box
  4. Assign to any agency and at least one group
  5. Set a password for the account — you will need this in Step 3
  6. ⚠ TAK Portal appends an org suffix to every username (e.g. cloudtakadmin-orgname). Note the full suffixed username shown after creation — that is what you enter in CloudTAK, not just cloudtakadmin.
STEP 2 — Generate & download the Bootstrap Admin certificate

CloudTAK 13.59+ (Core Events) reposts Events over this certificate and silently skips channels the cert can't reach — it needs a channels-disabled admin cert, not a regular user cert. This button creates cloudtak-svc-bootstrap.p12 with exactly that shape (makeCert-issued + ROLE_ADMIN — an admin cert bypasses channel selection and resolves every group, including channels created later).

Already running CloudTAK? Generate + download here, then swap it once in CloudTAK Admin → Server → Admin Certificate — no re-bootstrap needed. (The legacy user.p12 still connects, but Events will not deliver with it.)

STEP 3 — Configure CloudTAK on first launch
  1. Open CloudTAK in your browser{% if settings.fqdn %} at https://map.{{ settings.fqdn }}{% endif %} — if the setup/config page does not appear, wait a minute and reload (CloudTAK may still be starting); if it stays stale, clear it via DevTools → Application → Clear site data
  2. When prompted for the TAK Server address, enter: {% if settings.fqdn %}takserver.{{ settings.fqdn }}{% else %}takserver.yourdomain.com{% endif %}
  3. Enter username: cloudtakadmin-suffix (the full suffixed name from Step 1) and the password you set in Step 1
  4. Upload cloudtak-svc-bootstrap.p12 from Step 2 and enter the certificate password shown there
  5. CloudTAK will save and reload to the login page — sign in with your cloudtakadmin-suffix credentials

This is a one-time bootstrap to connect CloudTAK to TAK Server. After setup, additional users just create a TAK Portal account and log into CloudTAK with their username and password — no .p12 required.

Plugins upstream docs ↗

Plugins are baked into the CloudTAK SPA at build time — installing or removing one rebuilds the api image (5–15 min). CloudTAK stays running during the build and is briefly restarted at the end. After install, open CloudTAK → Settings → Refresh App to activate the new service worker. The plugin then appears at the bottom of the right-side menu. (A refresh — even Cmd/Ctrl+Shift+R — does not help; CloudTAK's service worker serves a cached copy. If Settings → Refresh App doesn't update it, clear it: DevTools → Application → Clear site data, then reload.)

Deploy CloudTAK

CloudTAK is a browser-based TAK client built by the Colorado DFPC Center of Excellence. It connects to your TAK Server and provides a full map interface in any web browser. Video streams from your standalone MediaMTX install will be used automatically.

First deploy builds Docker images and can take 10–15 minutes. Keep the tab open; if the log stops updating, refresh the page to reconnect.

🔑 Reset CloudTAK Server Config?

This clears the stored TAK Server connection (URL, cert, and admin account) from CloudTAK's database so you can re-run the bootstrap wizard with new TAK Server details.

Your map data and tile layers remain intact. Only the TAK Server connection is cleared.

⚠ Uninstall CloudTAK?

This will stop and remove all CloudTAK Docker containers, volumes, and the ~/CloudTAK directory. This cannot be undone.
