# Security

## Reporting a vulnerability

Please report it privately: open this repository's **Security** tab and choose
**Report a vulnerability**
([direct link](https://github.com/takwerx/infra-TAK/security/advisories/new)).
Do not open a public issue, and do not post details, logs or proof-of-concept
data where others can read them.

## Supported versions

Only the latest release gets security fixes. Update before reporting.

## What to expect

We acknowledge a report within 3 working days, tell you whether we can
reproduce it, and keep you updated until a fix ships. Confirmed issues are
fixed in a new release and credited to you if you want.

## Scope

The console and its modules, the broker and helper services, the install and deploy scripts, and how infra-TAK configures TAK Server, Authentik, Caddy, CloudTAK, TAK Portal and the other services it manages. infra-TAK runs CJIS-class deployments, so responsible disclosure protects real agencies: please give us time to ship a fix before you disclose. Vulnerabilities in the upstream projects themselves belong with those projects.
